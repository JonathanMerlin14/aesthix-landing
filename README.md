
# AESTHIX - Fitness Wear Landing Page

**AESTHIX** es una marca de ropa deportiva que representa fuerza, estética y superación personal. Esta landing page fue desarrollada con **Tailwind CSS** como parte del portafolio web de [Jonathan Merlin](https://github.com/JonathanMerlin14), y está enfocada en el lanzamiento de sus colecciones exclusivas: **AURA** (mujer) y **ATHLYON** (hombre).

![Hero Preview](https://via.placeholder.com/1200x600.png?text=Vista+de+Inicio+AESTHIX)

---

## Tecnologías utilizadas

- **HTML5**
- **Tailwind CSS CDN**
- **Google Fonts**: *Playfair Display*, *Inter*
- **Diseño Mobile-First**
- **Preparado para integración con Stripe o Shopify**

---

## Características

- Diseño moderno y minimalista, en tendencia con marcas como *YoungLA* y *AYBL*.
- Tipografía elegante con fondo oscuro para transmitir fuerza y exclusividad.
- Sección de colecciones destacadas (AURA y ATHLYON).
- Estructura limpia y escalable.
- Listo para ser extendido con animaciones, preventas o tienda online.

## Cómo usar

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tuusuario/aesthix-landing.git
   cd aesthix-landing
   ```

2. Abre `index.html` en tu navegador o edítalo en tu editor favorito.

3. Para deploy gratuito, puedes usar:
   - [Netlify](https://www.netlify.com/)
   - [Vercel](https://vercel.com/)
   - [GitHub Pages](https://pages.github.com/)
